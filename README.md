## 🚀 Getting Started

To run this practice environment locally:

1. Install dependencies:
   ```bash
   npm install
   ```
2. Start the development server:
   ```bash
   npm run dev
   ```
3. Open your browser and cast your vote carefully. Or don't. The system knows what's best anyway.

## 🎵 Audio Configuration

To enable the sound effects, ensure the following files are placed in the `public/assets/` directory:
- `violin.mpeg` - Plays when you make the correct, glorious choice.
- `gay.mpeg` - Plays when you attempt to throw your vote away.
